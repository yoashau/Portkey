范围限定为 UI、绘制和交互，没有修改连接、健康检测、SSH 或远端配置逻辑，也没有主动运行网络/部署验收。

审查修正：

- 菜单文字发灰：文字绘制层重复乘了共同祖先的透明度。修正后启用项达到实际前景色；真正禁用的控件仍保留降低后的对比度。新增像素回归在修正前失败（通道差值 72），修正后 System / Light / Dark 均为 0。
- 问号与开关交互混在一起：将开关说明移出 CheckBox 的点击与键盘事件路径，保持独立的悬停、聚焦帮助。
- 裁剪更新遗留文字：原先只在文字内容或位置变化时刷新，单独改变祖先裁剪不会更新绘制层。增加裁剪及可变几何/变换订阅，以完整矩阵重新应用裁剪；修正前的像素检查失败，修正后裁剪外无文字泄漏。
- 矮工作区隐藏操作及窗口高度恢复：主页在高度不足时滚动，回到正常工作区打开时恢复 456 DIP。实测 300 DIP 下日志入口可滚动到，重新打开恢复无滚动布局。
- 已销毁托盘控制器的窗口回调：改为可解除的具名订阅，关闭后解除事件。测试确认随后改变面板尺寸不会再触发旧控制器定位。

同时保证绘制层从创建时即不参与命中或焦点；绘制缓存包含字形、字体实例和 DPI，位置/裁剪变化复用字形几何。原生输入框的选择、撤销、水平滚动、复制菜单与辅助功能均保留。
